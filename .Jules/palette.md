## 2024-05-18 - Missing ARIA Labels on Icon-only Action Links\n**Learning:** The project's codebase frequently implements icon-only action buttons (e.g., using `Link` or `button` elements for View/Edit/Delete actions in data tables like `.edit-delete-action`) that lack `aria-label` attributes, making them inaccessible to screen readers which will only announce them as "link".\n**Action:** When working on similar data table components, always proactively check for and add missing `aria-label` attributes to icon-only action links/buttons to ensure robust screen reader support.
