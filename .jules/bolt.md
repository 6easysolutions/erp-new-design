## 2024-05-24 - Unmemoized Array Filtering Anti-Pattern\n**Learning:** The codebase contains a prevalent anti-pattern of filtering large static datasets synchronously inside component render functions without memoization (e.g., `const filteredData = data.filter(...)`). This creates O(N*M) bottlenecks during unrelated component re-renders.\n**Action:** When working in this codebase, always proactively scan for and wrap repetitive array filtering operations with `useMemo`.
