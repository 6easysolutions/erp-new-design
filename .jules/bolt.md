## 2024-05-24 - Array Filtering Anti-Pattern\n**Learning:** Large static datasets are being synchronously filtered inside component render functions without memoization (e.g., `const filteredData = data.filter(...)`), causing unnecessary recalculations on unrelated re-renders.\n**Action:** Use `useMemo` to wrap these operations and only re-filter when dependencies (like the dataset or search query) change.
