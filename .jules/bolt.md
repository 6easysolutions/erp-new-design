## 2024-03-24 - [Avoid Multiple Array Passes in UI Components]
**Learning:** Found a common anti-pattern across `StockTransfers.jsx`, `InventoryCounts.jsx`, and `StockAdjustment.jsx` where summary statistics were computed using multiple separate `.filter(...).length` passes inside `useMemo` blocks, causing unnecessary O(k*N) time complexity where N is the array length and k is the number of stats.
**Action:** Replaced these separate filter passes with single-pass `for...of` loops, executing all statistics accumulation simultaneously to improve O(k*N) to O(N). This strategy is generally safer for complex derivations that shouldn't re-render frequently and minimizes array allocations in React.
