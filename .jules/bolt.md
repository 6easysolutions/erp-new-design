## 2024-05-24 - Unmemoized Static Dataset Filtering Anti-Pattern
**Learning:** Found a prevalent anti-pattern where components filter large static datasets (like `saleslistdata`, `datas`, etc. from JSON) synchronously inside the component body, without memoization. Further compounding the issue, string conversions like `searchText.toLowerCase()` were placed inside the innermost loop `Object.keys(entry).some(...)`, causing an O(N*M) redundant re-evaluation on every single render (even unrelated ones).
**Action:** When working with search/filter features on datasets, always wrap the filtered array computation in `useMemo`. Also, always extract invariant operations (like `const lowerSearchText = searchText.toLowerCase()`) outside of the filter/some loops to prevent unnecessary allocations and computations.
