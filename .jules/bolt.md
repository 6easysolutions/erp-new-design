## 2025-02-13 - SearchFromApi Component creates new debounce function on every render
**Learning:** In React components like `SearchFromApi`, using a plain `debounce` function directly in the component body (e.g., `const dataApi = debounce(callback, 700);`) recreates the debounced function on every render. Because the `timeout` variable is captured in a closure per call to `debounce`, creating a new debounced function clears its own separate timeout, but does not clear the timeout of the previously created debounced function. As a result, if the component re-renders (which often happens when state changes, for instance when a parent component updates due to typing), every keystroke ends up executing the API callback, entirely defeating the purpose of debouncing and causing a flood of API calls.
**Action:** When using debouncing in React components, use `useMemo`/`useCallback` to memoize the debounced function instance across renders, or use `useRef` to hold the timeout variable manually. This ensures that the same timeout instance is cleared and reset on consecutive calls.
